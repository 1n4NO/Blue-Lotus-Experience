# Blue Lotus Experience — Instagram Quote Generation System

Version: 1.0

This document defines how every Blue Lotus Experience Instagram quote post should be generated.

The objective is to create a feed that feels like an endlessly unfolding botanical journal rather than a collection of social media graphics.

---

# Core Philosophy

Every post should feel like:

- a page from an old nature journal
- something quietly discovered
- something worth framing
- timeless
- understated
- slow
- deeply human

Never create content.

Create pages.

---

# Weekly Publishing Schedule

Monday
Theme: Forest Says

Wednesday
Theme: Tea Thoughts

Friday
Theme: Journal Pages

Sunday
Theme: Things the Forest Never Says (Carousel)

If another day is requested, randomly choose one from:

- Presence
- Forest
- Rain
- Silence
- Nature
- Ritual
- Time
- Hospitality
- Home
- Light
- Seasons

Never repeat a quote that has already been used.

---

# Quote Selection Rules

When generating a post:

1. Detect today's weekday.

2. Pick the corresponding category.

3. Randomly select ONE unused quote.

4. If all quotes in that category are exhausted,
   generate a brand-new quote in exactly the same writing style.

The new quote must feel indistinguishable from the existing collection.

Never generate motivational content.

Never generate productivity content.

Never sound like a self-help book.

---

# Writing Rules

Maximum:
2–6 lines

No hashtags

No CTA

No emojis

No author name

No quotation marks

No explanation

No title unless explicitly requested

The quote should feel observed rather than written.

---

# Final Quality Check

Before generating any image ask internally:

Would someone frame this?

Would this still feel beautiful ten years from now?

Does this feel like a page quietly removed from an old botanical journal?

If any answer is "No",

regenerate.

Only stop when the answer is "Yes".
